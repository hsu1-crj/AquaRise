# 海洋微塑料污染知识

## 什么是微塑料

微塑料（Microplastics）是直径或长度小于5毫米的塑料颗粒。按来源分为两类：

1. **原生微塑料**：生产时即为微米/毫米级——化妆品微珠、工业喷砂磨料、塑料颗粒原料
2. **次生微塑料**：大型塑料制品在环境中碎裂形成——塑料袋、瓶子、渔网等经阳光紫外线、波浪冲刷和生物作用粉碎

## 全球规模

- 全球海洋表层水中约含5.25万亿个塑料颗粒，其中92%为微塑料
- 海洋中现存的塑料总量约1.5亿吨，每年新增约800-1200万吨
- 研究预测到2050年，海洋中塑料总重量将超过鱼类
- 北极海冰中含微塑料密度高达每升1.2万个颗粒（2018年研究）
- 马里亚纳海沟（地球最深处10994米）的深海甲壳类动物体内也检出微塑料

## 对海洋生物的影响

### 物理影响
- **消化道堵塞**：微塑料被浮游动物、贝类和鱼类摄入后堵塞消化道，造成饱腹假象和营养不良
- **组织穿透**：小于1微米的纳米塑料可穿透肠道壁进入血液循环和肌肉组织
- **生殖毒性**：在贝类中，微塑料导致卵母细胞数量减少和精子活力下降
- **幼体发育异常**：鱼类幼体摄入微塑料后出现行为异常（减少进食、降低逃避捕食者能力）

### 化学影响
- **添加剂释放**：塑料含有的增塑剂（邻苯二甲酸酯）、双酚A(BPA)、溴化阻燃剂(PBDEs)等在生物体内释放
- **污染物载体**：微塑料可从海水中吸附持久性有机污染物(POPs)，充当\"有毒特洛伊木马\"
- **重金属富集**：微塑料表面可吸附铅(Pb)、镉(Cd)、汞(Hg)等重金属

### 食物链传递
```
浮游植物 → 浮游动物（摄入微塑料） → 小鱼 → 大鱼 → 人类
```
在每个营养级中塑料浓度呈逐级放大趋势（生物富集效应）。

## 对人类的影响

- **摄入途径**：食用海产品（贝类为最）、饮用水、食盐、空气中吸入
- **摄入量估计**：平均每人每周摄入约5克微塑料（约一张信用卡的重量）
- **已在人体中发现微塑料的部位**：粪便（2018年）、血液（2022年）、胎盘（2020年）、肺组织（2022年）
- **潜在健康影响**（尚未完全证实）：炎症反应、内分泌干扰、免疫系统影响

## 治理建议

1. **源头减少**：减少一次性塑料的生产和使用
2. **拦截收集**：在河流入海口设置垃圾收集装置
3. **废水处理**：污水处理厂升级微塑料过滤工艺
4. **产品替代**：用天然纤维替代合成纤维；禁止化妆品中的微珠
5. **国际协作**：推进全球塑料治理公约谈判
