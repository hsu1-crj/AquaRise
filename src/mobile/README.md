# AQUARISE 移动端 · 任务监控面板

水下垃圾自动识别与海洋污染分析系统的**移动端操作页面**，提供主机端检测任务的实时监控与浏览能力。

> 技术栈：原生 HTML + CSS + ES Modules，零构建步骤，零 npm 依赖。

---

## 设计目标

| 需求 | 实现 |
|------|------|
| 与网页端功能和样式呼应 | 复用 AQUARISE 深海玻璃拟态设计语言，同色系、同图标风格 |
| 主机端任务实时监控 | 3 秒轮询 `/detections` + 并发查询 `/detect/status/{id}`，获取任务阶段状态和实际处理耗时 |
| 不动网页前端和后端主干 | `src/mobile/` 完全独立，不修改 `src/frontend/` 和 `src/backend/` 任何文件 |
| 贴人性、落地化 | 大触控区域、底部 Tab 导航、振动反馈、状态变化推送、安全区适配 |
| 轻量化、稳定、后端兼容 | 零依赖纯静态文件，复用现有 `/api/v1/*` 接口，JWT 鉴权完全兼容 |
| 代码可读性和封装性 | 按职责拆分 `api.js` / `ui.js` / `main.js` / `pages/*.js`，每模块单一职责 |

## 快速开始

### 1. 确保后端在运行

```bash
cd src/backend
uvicorn main:app --host 0.0.0.0 --port 8000
```

> `--host 0.0.0.0` 确保局域网内的手机可以访问。

> **重要**：移动端必须使用与主机端**相同的账号**登录。检测任务按用户隔离，只有提交任务的账号才能在移动端看到对应的任务记录。

### 2. 启动移动端静态服务器

```bash
cd src/mobile
python serve.py
```

终端会打印局域网地址，例如：

```
  局域网访问: http://192.168.1.100:8080
```

### 3. 手机访问

1. 手机连接同一 WiFi，浏览器打开 `http://192.168.1.100:8080`
2. 在登录页展开「服务器连接设置」，输入后端地址 `http://192.168.1.100:8000`
3. 点击「测试连接」，系统会自动验证地址格式、连通性以及是否为 AQUARISE 后端（检查 `service === "海洋守护者 API"`），验证通过后才会保存地址
4. 使用项目账号密码登录

## 功能说明

### 实时任务监控（核心）

- **自动轮询**：每 3 秒拉取任务列表，对「处理中」任务并发调用 `/detect/status/{id}` 获取任务阶段状态（排队 / 推理中 / 完成）和实际处理耗时
- **状态合并**：将 `/detect/status` 返回的权威状态合并回任务字段，确保 UI 分类、进度展示和完成通知使用最新值
- **置顶高亮**：进行中任务显示在页面顶部，带进度指示
- **状态推送**：任务从「处理中」变为「已完成」或「失败」时，自动 Toast 通知 + 振动
- **省电模式**：页面切到后台时自动暂停轮询并中止在途请求，切回时立即恢复
- **请求保护**：AbortController + 互斥锁，页面卸载后不残留请求，慢网络下轮询不重叠

### API 地址安全

- 地址保存前先校验格式（必须 `http://` 或 `https://` 开头）
- 登录前如地址变更，先探测连通性并验证后端身份，通过后才保存，避免错误 IP 覆盖已有地址
- 测试连接和保存按钮均执行「先探测、成功才保存」流程

### 页面总览

| 页面 | 对应桌面端 | 移动端侧重 |
|------|-----------|-----------|
| 态势总览 | Dashboard | 核心指标 + 快捷入口 + 趋势微缩图 |
| 实时监控 | —（新增） | 主机端任务实时状态追踪 |
| 检测历史 | History | 筛选 + 分页浏览 |
| 任务详情 | Detection 结果 | 材质分布 + 目标列表 + 一键生成报告 |
| 个人中心 | Profile | 资料编辑 + 改密 + 服务器地址管理 |

## API 兼容性

移动端 **完全复用** 桌面端后端接口，无任何后端改动：

| 接口 | 用途 |
|------|------|
| `POST /api/v1/auth/login` | 登录获取 JWT |
| `GET /api/v1/auth/me` | 当前用户信息 |
| `GET /api/v1/stats/summary` | 统计概览 |
| `GET /api/v1/stats/trend` | 趋势数据 |
| `GET /api/v1/detections` | 检测任务列表（按当前用户过滤） |
| `GET /api/v1/detect/status/{id}` | 任务实时状态（阶段 + 耗时） |
| `GET /api/v1/detect/result/{id}` | 检测结果详情 |
| `POST /api/v1/reports/` | 生成检测报告 |

`api.js` 中对 `summary` 和 `trend` 做了 DTO 归一化，同时兼容 camelCase 和 snake_case 返回格式。

## 架构说明

- **零构建步骤**：所有 JS 使用原生 ES Modules（`import`/`export`），由浏览器直接加载，无需 npm/webpack/vite
- **独立部署**：`src/mobile/` 与 `src/frontend/`、`src/backend/` 完全解耦，不修改任何现有代码
- **可配置 API 基址**：手机端将服务器地址持久化到 localStorage，支持在登录页和个人中心修改
- **CORS**：后端已配置 `allow_origins=["*"]`，手机跨域请求开箱即用
