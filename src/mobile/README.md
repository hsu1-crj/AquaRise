# 海瞳 HAITONG 移动端

海洋全域智守平台的独立移动体验，定位为“随身监测与快速处置终端”。实现仅位于 `src/mobile/`，不修改或复用 PC 页面布局。

## 能力

底部固定五个一级入口：

- **首页**：当前任务海域、活跃任务、预警摘要、近 7 日轻量趋势和最近任务；
- **识别**：拍照、相册、多图文件和视频上传，展示真实上传进度；
- **任务**：进行中、历史、报告三个分段页，支持搜索、筛选、报告查看/分享和 AI 解读；
- **守护者**：按需加载的文本流式对话，可带入任务摘要或报告上下文；
- **我的**：资料、安全、服务器、任务通知、省流模式、减少动效和缓存管理。

“污染分析简报”和“2D 海域态势”从首页进入。Three.js、ECharts、数字人 SDK 和视频播放器不进入首屏依赖。

## 启动

1. 启动 FastAPI 后端：

   ```bash
   cd src/backend
   uvicorn main:app --host 0.0.0.0 --port 8000
   ```

2. 启动独立移动静态服务器：

   ```bash
   cd src/mobile
   python serve.py
   ```

3. 手机与主机连接同一网络，打开终端输出的 `http://<主机局域网IP>:8080`。
4. 首次登录时，在“高级连接设置”中填写 `http://<主机局域网IP>:8000` 并测试连接。

## 行为约束

- 页面后台或锁屏时停止任务轮询并中止在途请求，回到前台立即同步一次；
- 有活跃任务时每 3 秒同步，无活跃任务时每 15 秒同步；任务状态并发查询限制为每批 4 个；
- 图片单批最多选择 9 张，单图最大 20 MB；视频最大 500 MB；
- 视频在明确检测到非 Wi-Fi 或系统省流模式时二次确认；
- 列表与详情媒体按需加载，视频不自动播放；
- 报告预览先通过 Bearer 鉴权获取，再以本地临时 URL 打开；
- 登录、详情和报告数据不写入离线缓存。

## 复用接口

移动端复用既有 `/api/v1/*`：认证、统计、海域、检测、任务状态、检测结果、报告和聊天。未新增后端或 PC 端修改。

## 验收视口

重点覆盖：`360 × 800`、`390 × 844`、`430 × 932`、`768 × 1024`。页面左右边距、安全区、底部导航和详情操作栏均按对应视口适配。
