## 一、重大升级总览

今日对 **海瞳 · 全球濒危海洋生物生命图谱 (Bioluminescent Marine Atlas)** 进行了全方位的系统级架构与体验升级：
1. **全球物种档案库扩充**：整合来自 IUCN 濒危物种红色名录 (IUCN Red List)、NOAA Fisheries 官方物种名录与世界自然基金会 (WWF) 权威资料，扩展为 **22 份高规格海洋生物档案**（覆盖 9 种极危 CR、5 种濒危 EN、4 种易危 VU 以及 4 种史料已灭绝 EX 物种），并全面纳入 5 大生物分类群（海洋哺乳类、鲨鱼与鳐鱼软骨鱼类、海龟爬行类、硬骨与深海鱼类、无脊椎与珊瑚、海洋鸟类）。
2. **极简高级搜索与多维分类中枢**：
   - **顶置悬浮玻璃控制中枢 (`#filterHub`)**：集成保护等级分段胶囊（带实时物种计数徽标：全部 22、极危 9、濒危 5、易危 4、消逝 4）与生物类群轻量筛选轨。
   - **全局 Spotlight 级智能检索 (`#spotlightModal`)**：支持 `/` 或 `Cmd/Ctrl+K` 快捷呼出；支持中文名、拼音、英文名、学名、威胁标签（如 `#鱼翅`、`#刺网`、`#活化石`、`#塑料`）即时模糊匹配；带缩略图预览与键盘（`↑` `↓` `Enter` `ESC`）流畅交互。
3. **AI 手势图鉴仿手动态升级**：为全部 12 种 YOLO26 识别手势定制了发光矢量手形插画与微动效指示，并支持在图鉴卡片内直接点击模拟执行手势。
4. **底层 GPU 渲染与视口居中修复**：
   - 重构 CSS Stacking Context，彻底根除负 `z-index` 画布被遮挡的黑屏隐患。
   - 升级 Three.js 9,200 粒子生物荧光渲染管线，实现视口绝对中心环形出生与平滑卷流噪声。
   - 惯性物理滚动与右侧深海下潜刻度条（0m ~ 11,000m）。

## 五、体验修复与前后端扩展（晚间补丁）

### 1. 首屏叙事重做

- 新增粒子签名序列：粒子先聚成“海瞳”未来之眼，再在约 4.3 秒内重组为带明暗层次的立体圆球，最后进入可下潜的生命星云状态。
- 用户第一次滚轮、拖动或触摸时可立即接管，不会被开场动画阻塞；系统开启“减少动态效果”时自动跳过序列。

### 2. 搜索定位闭环

- 搜索结果现在会同时显示本地图像、中文名、英文名、学名、保育等级和威胁标签。
- 点击或按 `Enter` 定位后，自动切换到对应生物、显影图片、打开完整介绍并锁定档案；卡片新增“解除固定”，避免出现“搜索有结果但页面没有变化”的断裂感。
- 搜索定位会清除筛选冲突，保证被搜索的生物一定能被看见；支持 `/`、`Cmd/Ctrl+K`、上下键和 `Esc`。

### 3. 手势与替代操作

- 掌手交互改为纯时长控制：只识别张开手掌的持续时间，保持越久显影越深，不再读取掌宽、前后距离或执行掌距校准；离手/换手势即重置计时。
- 横向挥手切换保留为独立动作，单向移动超过阈值即可切换，不再要求先反向挥动。
- 摄像头服务未启动时会直接提示启动方式，不再静默进入“无反应”状态。
- 新增统一鼠标/触摸指针交互：纵向拖动下潜，横向滑动切换物种；滚轮、键盘和底部按钮继续可用。

### 4. 后端可扩展接口

- `GET /api/catalog`：返回当前 22 份完整档案目录。
- `GET /api/catalog/search?q=鲸鲨`：按中文名、英文名、学名、等级、类群、威胁标签和介绍检索。
- 目录接口暂时从前端单一档案源生成，后续可无缝替换为数据库或 CMS；客户端契约已经固定。
- `POSE_MODEL` 改为读取 `HAITONG_POSE_MODEL` 环境变量或项目内模型，不再依赖个人电脑上的绝对路径；`start.bat` 支持 `HAITONG_PYTHON`，找不到默认环境时回退到系统 Python。

### 5. 清理结果

- 删除开发期间生成的临时 QA 脚本与 Python 缓存目录，保留模型、图片、音频和 Three.js 运行时等必要资源。

### 6. 8.17 交互微调

- 物种展示卡片改为“档案状态 → 生物名称 → 保育故事 → 图像来源 → 操作按钮”的明确层级。
- `查看档案`、`保存图片`、`解除固定/回到星云` 分为主要、次要和状态动作，按钮获得统一悬停与键盘焦点反馈。
