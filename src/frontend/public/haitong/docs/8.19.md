## 一、问题复现

- 手势下潜时 `targetZoom` 固定为 `0.92`，但照片显影终点设为 `1.0`，导致粒子和照片永远停在半成品状态。
- 粒子转场使用 CPU 跟随阻尼，预设结束后没有最终对齐帧，低帧率或快速操作时会留下未归位粒子。
- 动物返回地球时，图片层仍沿用上一帧的显影状态，collapse 末段会短暂闪回旧动物图片和卡片。
- `fragment` 转场分支存在重复空分支，实际逻辑被遮住，已灭绝物种切换没有执行预期的边缘剥落效果。
- 海洋粒子底色和夜侧透明度偏低，昼夜计算会把深洋压暗，海洋读起来像空白区域。

## 二、修复内容

### 转场状态

- 将照片显影终点统一到实际手势可达的 `0.92` 深度。
- 每个粒子预设结束时安排下一帧最终对齐，消除粒子卡在中间形态的问题。
- current 切换期间暂时隐藏照片层，等粒子转场完成后再显示新图片，避免跳图和旧图闪现。
- collapse 开始时立即清零照片层、隐藏档案卡片，整个回收过程不再显示旧动物。
- 清理重复的 `fragment` 空分支，恢复已灭绝物种的粒子碎片转场。
- 保留单一 Three.js 渲染器、单一 `BufferGeometry` 和 `ShaderMaterial`，粒子数量不变。

### 地球亮度与海洋

- 提高昼夜基础光照，夜侧保留蓝色海洋底光，仍保留右上柔和昼夜分界。
- 深洋与大陆架使用更亮、更有层次的蓝青色，并根据稳定 `bathymetry` seed 调整点大小。
- 增加稳定的深海洋流明暗带，让海洋呈现连续水体和流动纹理，而不是空的点阵背景。
- 提高海洋前景透明度，并保留可读的背面海洋底色。

### 2. 地球高速旋转变橄榄球形变缺陷彻底根治
- **问题根因分析**：原代码在待机与自转时，对计算好的 3D 刚体旋转坐标执行了 CPU 低通平滑滤波（`p.x += (targetX - p.x) * 0.08`）。由于自转仅在经度水平 X 轴发生高频正弦位移，低通滤波使得 X 轴振幅随转速急剧衰减至 $2R \times \frac{k}{\sqrt{k^2+\omega^2}}$，而未自转的纬度 Y 轴保持全直径 $2R$，导致高速旋转时球体被向心压扁成直立橄榄球/足球形状。
- **正圆刚体数学修复**：在 planet 状态下核心粒子直接对齐 3D 刚体旋转坐标（`snapThisFrame || shapeT < 0.02`），无论用户拖拽或手势旋转多快，球体几何始终保持 100% 完美无畸变正球体。
- **极速旋转星光流线 (Kinetic Star Trails)**：旋转速度越快，周围稀疏环境星尘粒子自动增加流光加速与光晕，呈现宛若星际曲速航行般的炫酷星光效果，取代原本丑陋的几何形变。

### 4. 纯离线 Web Audio 鲸落仪式全景音效合成器
- **零外部网络依赖**：内置高品质 Web Audio 程序化声音合成器 (`playWhaleFallFx`)，在点赞或自动演示触发鲸落时实时生成 5 阶段交响级仪式音效：

  - **阶段二：52Hz 蓝鲸多共振峰空灵吟唱 (Whale Song)**：双载波失谐（52Hz & 52.4Hz）+ 6.2Hz 呼吸颤音 FM 调频与滑音曲线。
