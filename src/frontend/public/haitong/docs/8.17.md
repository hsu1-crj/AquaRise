## 三、地球无法显示回归修复（2026-08-17）

### 1. 根因

- **前端启动被海报灯箱空节点中断**：本次海报重构加入了 `#posterLightbox`、`#lightboxImg`、`#closeLightbox` 的样式和事件代码，但遗漏了对应 HTML。页面加载到灯箱事件绑定时触发 `TypeError: Cannot read properties of null (reading 'addEventListener')`，后续 Three.js 初始化没有执行，`#stage` 停留在浏览器默认的 `300×150`，因此地球完全不可见。
- **摄像头在动画循环中被反复自动启动**：`frame()` 每帧都调用 `autoStartGesture()`，初始化末尾又额外调用一次。摄像头识别到手掌后会立即把深度推至 `11000m`，页面从地球态切到物种照片；即使用户关闭手势，下一帧也会再次启动，造成“地球仍然不显示”的第二层症状。

### 2. 修复

- 补回完整的海报全屏灯箱 DOM，恢复 `posterLightbox`、`lightboxImg`、`closeLightbox` 三个前端契约节点，保留点击预览、点击空白处关闭和 `ESC` 返回能力。
- 从 `requestAnimationFrame` 主循环中移除音乐和摄像头启动副作用；背景音只在初始化阶段尝试一次。
- 取消页面启动时自动开启摄像头，恢复为用户点击“手势”后才启用识别。关闭手势后不再被下一帧重新打开，首屏稳定保持粒子地球待机态。
- 新增 `tests/frontend-smoke.html`：通过真实同源页面验证脚本/WebGL 舞台完成初始化，并检查首屏深度为 `0m`、手势未自动激活。

### 3. 红绿回归与浏览器验证

- **修复前启动用例**：`FAIL`，`window.__LIFE=false`、`window.__SIM=false`、画布为 `300×150`。
- **修复前地球待机用例**：`FAIL`，实际状态为 `depth=11000m`、`gestureClass="pill-btn active"`、摄像头预览为 `show`。
- **修复后冒烟用例**：`PASS: 应用启动后保持在可交互的地球待机态`。
- **实际浏览器视觉验证**：`1280×720` 视口下粒子地球完整显示；WebGL 画布实际缓冲区为 `1920×1080`，深度 `0m`，摄像头与预览均未自动开启。
- **控制台与交互**：无相关 `error` / `warn`，无框架错误遮罩；点击“下一物种”可从“小头鼠海豚”切换到“北大西洋露脊鲸”，地球仍保持显示。

### 3. 粒子地球叠加离线中国边界

- 保留原有 `THREE.Points + BufferGeometry + ShaderMaterial` GPU 点云，没有替换为 SphereMesh、贴图或网络地图。
- 显式定义粒子单位球半径 `EARTH_RADIUS = 1`，国界半径使用 `EARTH_RADIUS + BORDER_SURFACE_OFFSET`；`BORDER_SURFACE_OFFSET = 0.012` 将线条向球面外微抬，避免与表层粒子发生 Z-fighting 闪烁。
- 内置 `CHINA_GEOJSON_SIMPLIFIED` MultiPolygon，包含大陆主环、台湾岛和海南岛；运行时不 fetch 外部 GeoJSON，离线本机可用。
- 新增 `lonLatToSphere(lon, lat)`，按经纬度弧度、Y 轴向上的公式转换为球面三维坐标。
- 本地 `assets/vendor/three.module.min.js` 不包含 `Line2 / LineMaterial / LineGeometry`，因此按兼容方案保留原生 `THREE.LineSegments`，并使用自定义 `ShaderMaterial` 在片元阶段裁掉背半球；颜色为 `#ffdd77`，WebGL 环境实际线宽约 1px。

兼容型地球根结构如下：

```text
scene
└── planetRoot
    ├── particleProjectionLayer
    │   └── pointCloud（原 BufferGeometry + ShaderMaterial）
    └── chinaBorderGroup
        ├── LineSegments
        └── “中国” CanvasTexture 公告牌平面
```

- `planetRoot` 统一接收地球自转、原有 `23.44°` 地轴倾角和鼠标拖拽俯仰。

- 边界没有独立脉冲或闪烁动画，`prefers-reduced-motion` 下不会增加额外动态效果。

### 2. 夹捏旋转与慢速显影

## 六、地球朝向与开场纯净度终修（2026-08-17 二次反馈）

根据用户反馈“中国倒着放”与“海瞳粒子效果出现时还有其他东西”，完成两项视觉修复：

### 1. 地球正向显示（北极在上、中国正放、东西不镜像）

- **根因**：正交相机视口设置为 `top=0, bottom=H`，使世界坐标 `+Y` 映射到屏幕下方；而粒子 CPU 公式与国界/标签均按“`+Y` 朝上”设计。实测北极渲染在屏幕中心下方 366px，“中国”标签文字也上下颠倒（顶边 y=875 > 底边 y=810）。
- **修复**：`resize()` 中相机改为 `top=H, bottom=0`，世界 `+Y` 恢复为屏幕上方；粒子公式、国界与标签全部随相机统一正向，无需逐点改符号。
- **联动修正**：物种照片的形态坐标原按画布 y 向下编写，翻转相机后同步把照片中心 `Cy` 与逐点 `sy` 取反，粒子照片与 DOM 照片框中心（实测 397px vs 400px）与 1.15× 外扩范围保持一致。
- **顺带修复东西镜像**：实测北京（116.4°E）在喀什（75.98°E）左侧，即地图左右镜像（与上下颠倒合起来即 180° 翻转）。将球面模型 `x0` 与 `lonLatToSphere` 的 x 分量取反（`x = -cos(lat)cos(lon)`），东经恢复在屏幕右侧；自转方向随之符合真实地球（正前方经度随时间减小、地表自西向东流动），拖拽与夹捏手感不变。
- 23.44° 地轴倾角、背半球裁剪、标签公告牌与 1450ms 迁徙逻辑均未改动。

### 2. 开场海瞳阶段纯净（国界与“中国”标签不再提前出现）

- **根因**：`chinaBorderGroup.visible` 只按 `lifeMode==='planet'` 控制，与开场计时无关；海瞳眼部粒子成形时，金色国界线与“中国”标签已漂浮在地球位置。
- **修复**：`frame()` 中新增 `borderFade = introActive ? introMorph : 1`，开场期间国界随地球形态一起从 0 淡入（实测 0.79s 眼阶段 group 隐藏、透明度 0；1.7s 起 0.002→0.95 平滑过渡；4.3s 后满显）。
- 开场结束后不再每帧写入 `visible`，保留“控制台手动开关可持续到下一次模式切换”的既有契约；`dismissIntro()`（点击跳过开场）时立即恢复国界显示。

### 3. 验证

- `node tests/poster-utils.test.mjs`：通过。
- `tests/frontend-smoke.html`：新增“北极在中心上方”“北京在喀什东侧”“标签正向”“开场眼部阶段不显示国界”断言，全部 PASS。
- 实测浏览器：北极 +282px 在屏幕中心上方；北京 931px > 喀什 855px（东在右）；自转 2s 内北京 931→933 向右（东向）；开场 0.79-1.41s 无国界/标签；palm/fist/grip 交互后控制台零错误。

- 排查发现版图 `THREE.Points + PointsMaterial` 的 `size: 0.035` 在正交相机下按 `gl_PointSize` 原样输出（three.js 仅在透视投影下按 `scale / -mvPosition.z` 衰减），渲染成亚像素点、肉眼不可见；此前评审看到的“暖金描边”其实是主粒子云中 `china_border_stardust` 类型粒子（约 5px）的叠加，且该云不包含南海九段线。
- 修复：版图粒子改用轻量 `ShaderMaterial`，`gl_PointSize = uSize * uPixelRatio`（逻辑像素 7px），片元阶段按视图空间法向 `discard` 背半球——地球自转到背侧时版图不再从球体正面透视出来，与原有 LineSegments 半球裁剪语义一致。
- 删除主粒子云中的 `china_border_stardust` 与 `china_text_particle` 两类注入及对应渲染分支，版图轮廓统一由 `china-particle-points` 单一来源绘制。

### 2. 钓鱼岛、赤尾屿独立粒子轮廓

- GeoJSON 中钓鱼岛、黄尾屿、赤尾屿由粗略 5 顶点环升级为 7–8 顶点闭合多边形（钓鱼岛南北长条、黄尾屿、赤尾屿各自独立）；采样步长 0.12°、每条边至少 10 粒子，三岛分别约 70/60/70 个粒子点，正面视角可清晰辨认。
- 冒烟测试新增断言：钓鱼岛 ≥ 40 点、黄尾屿 ≥ 30 点、赤尾屿 ≥ 40 点。

### 3. 南海九段断续粒子线
