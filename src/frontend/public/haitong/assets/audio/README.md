## 音频构成与生成方式

1. **背景音乐 (`assets/audio/yue.mp3`)**：
   - 薛之谦《跃》，仅限内部研学交流使用。
2. **深海声景 (`assets/audio/ambience/deep-sea.wav`)**：
   - 海瞳项目原创程序合成深海声景（水流次声、洋流共鸣），非实地录音，亦非动物原声。
3. **鲸落彩蛋音效 (`assets/audio/easter-eggs/whale-fall.wav`)**：
   - 5 层物理合成深海巨鲸吟唱与海雪风铃音效（Web Audio / 离线合成），项目自有。
4. **22 种海洋生物个性化童声独白 (`assets/audio/species/*-voice.mp3`)**：
   - 运行 `python tools/generate_species_voices.py` 生成：
   - 基于 **Edge-TTS + SSML 细粒度角色与音调调控**，覆盖 9 大微软 Neural 中文发音人，并根据儿童短声道基频特征施加 `+45Hz ~ +92Hz` 调优，塑造出 22 种性格迥异的专属童声音色（软萌幼童、空灵少年、活泼女孩、傲娇卫士等）。

---

### 原声规范说明
项目严禁将合成声标为动物真实叫声。灭绝、无声或暂无经核验公开录音的物种保留“未加载”状态；后续引入真实录音时，必须逐条登记录音人、来源链接与许可。
