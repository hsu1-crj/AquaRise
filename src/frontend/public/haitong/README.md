# 海瞳 · 生命图谱 (Bioluminescent Atlas)

> 🌟 **项目总策划**：`mingzhe` (Executive Producer & Chief Planner)  
> ⚠️ **非商业与内部学习声明**：本项目内置背景音乐音频《跃》（演唱：薛之谦）仅供非商业性的**个人/内部学习、教学研究与学术交流**使用，音频版权归原作者及相关唱片公司所有。未经官方版权方授权许可，严禁用于任何形式的商业盈利行为或公开发布传播。

一个由 MediaPipe Hands 手势感应驱动的 3D 粒子海洋生命图谱。手势在浏览器端本地完成（WASM + 21 手部关键点），无需逐帧上传摄像头画面；26,400 颗生物发光粒子从地球点云平滑重组为物种全息图谱与真实照片，并支持深度下潜展开保育档案。核心图谱与手势资源离线内置；物种问答使用平台本地 LLM 链路，GBIF 全球观测分布为可选联网增强，断网时自动回退档案栖息地点。

---

## 🌟 核心特色与版本更新（2026-08-27）

- **生命图谱 × 本地海瞳助手**：物种卡新增桌面对话抽屉，沿用平台 `/api/v1/chat` 流式契约与登录令牌；首轮自动携带当前物种语境，支持停止、重新生成与安全 Markdown 渲染，不接入任何云端 LLM。
- **选择性 Bloom 生物荧光**：本地内置与 Three.js r160 兼容的 `postprocessing@6.38.3`，复用同一 WebGL 渲染器增强粒子高光；240 帧滚动平均持续低于 30 FPS 时自动释放后处理并回落基础渲染，系统减少动态效果设置下默认关闭。
- **GBIF 全球观测分布**：地球模式可按需读取当前物种真实经纬度记录，每种最多显示 100 点，缓存 7 天；普通进入页面不发起请求，展览演示仅串行预热本轮物种，连续两次失败后本会话静默停用联网并显示档案栖息地。
- **桌面端布局适配**：1280×720、1440×900、1920×1080 三档完成视觉回归；中等桌面宽度下检索与观测工具条下移，避免与顶栏控制重叠。

- **总策划与艺术指导**：由 **`mingzhe`** 担任总策划，以深海生物荧光美学与声光电粒子互动为核心，打造兼具科研严谨度与浪漫艺术张力的生命图谱。
- **22 份权威海洋物种档案**：收录 18 个 IUCN 受威胁海洋物种（9 极危 CR、5 濒危 EN、4 易危 VU）与 4 个已灭绝海洋物种（EX）。
- **22 种生物专属个性化童声独白矩阵**：
  - 基于 **Edge-TTS + SSML 细粒度角色与音调调控**，覆盖 9 大微软 Neural 发音人。
  - 根据儿童短声道基频特征（$250\text{Hz} \sim 400\text{Hz}$）施加 `+45Hz ~ +92Hz` 的音调提升，塑造出 22 种性格迥异的童声音色（如软萌幼童、空灵少年、活泼海龟、傲娇卫士、消逝哀歌等）。
  - 点击物种档案「声纹回响」即可播放，并实时由 Web Audio Analyser 驱动声波光环扩散与粒子跳动。
- **七大核心手势与手势图鉴**：
  - **6 大标准交互手势**：`palm`（持续张开下潜显影）、`fist`（握拳回收重归地球 / 跳过鲸落）、`ok`（OK 手势固定/解锁档案）、`palm swipe`（手掌左右挥动翻页）、`one / point`（单指旋转地球）、`call`（电话"6"手势启停音乐）。
  - **OK 手势高精度矢量动效**：重塑发光全息能量双圈、瞄准准星与呼吸微旋动效（`.anim-ok`）。
  - **深海终极彩蛋（竖大拇指 👍 `like`）**：在地球模式下竖大拇指触发深海巨鲸坠落与百年绿洲演化，图鉴底部新增神秘浪漫彩蛋引导卡片。
- **六大顶级浪漫交互与视听特性**：
  1. **深海声呐光环 · 粒子引力波纹场**：独白播放或声纹回响时，以物种心脏为振源向三维深海中发散同心生物荧光声波光环，物理推开并激发微粒发光。
  2. **全球深海洋流生命光带**：赤道暖流与两极底层流之间，粒子按温度（暖金至冰蓝）沿测地线永恒巡航，串联 22 个濒危物种信标。
  3. **灭绝物种时光回溯重构**：切换至大海雀、斯特拉海牛等 EX 物种时，启动时光倒流螺旋粒子重组算法，全场色调沉降为深渊暗红与琥珀金，悬浮 `TIME REVERSAL` 徽章。
  4. **夜光藻触碰流光轨迹**：指针或手势划过水域时，轨迹经过的暗区微粒实时激发生物冷光反应（马祖蓝眼泪），留下流光拖尾。
  5. **极境深潜呼吸冥想视界**：静止 12 秒后 UI 优雅半透渐隐，整片粒子云以人类平静呼吸节律（每分钟 6 次）缓缓收缩与扩张。
  6. **鲸落四幕全景生态演化史诗**：完整呈现移动清道夫期 ➔ 机会主义者期 ➔ 化能自养期 ➔ 礁岩绿洲期四幕演替，联动 5 层离线 Web Audio 合成器（36Hz次声、52Hz蓝鲸吟唱、入水冲击、海雪玻璃琴风铃、新生心跳脉冲）。
- **全球粒子地球与真实感光照**：
  - **26,400 个 GPU 粒子**（24,000 核心 + 2,400 大气光幔），`THREE.Points + BufferGeometry + ShaderMaterial` 单批次点云。
  - 离线内置 720×360 世界陆地掩码（`EARTH_MASK_720`）渲染全球大陆、海岸线、深海与经纬网，不突出显示任何单一国家或地区。
  - **昼夜晨昏线光照与自转畸变动态补偿**：高速自转时自适应锁定球体外形，避免离心畸变。

## 🚀 启动方式

### 方式一：Windows 一键启动（推荐）
直接双击根目录下的 `start.bat`，脚本会自动探测服务状态并调用系统默认浏览器打开：

```text
http://127.0.0.1:8765/
```

`start.bat` 会先探测 `http://127.0.0.1:8765/api/health`：若海瞳服务已在运行，不会重复启动、也不会报端口冲突，而是直接呼出浏览器。

### 方式二：命令行手动启动
在已安装依赖的 Python 环境中运行：

```powershell
python gesture_server.py
```

- **后端核心依赖**：`fastapi`、`uvicorn`。
- **前端粒子引擎**：本地 `assets/vendor/three.module.min.js`（Three.js）。
- **手势推理引擎**：本地 `assets/vendor/mediapipe/`（MediaPipe Hands WASM + `hand_landmarker.task` 模型，离线内置，无需 Python 推理服务）。
- **摄像头权限**：仅需在浏览器页面中点击允许，画面在本地以约 30fps 实时提取 21 个手部三维关节点，绝不向外网传输任何图像数据。

## 🖐️ 交互操作指南

### 鼠标与键盘辅助控制
- **滚轮滚动**：展开 / 回收粒子与真实照片。
- **拖动旋转**：地球模式旋转经纬；物种模式纵向调整下潜深度、横向滑动切换物种。
- **键盘方向键 `←` / `→`**：快速切换上一只 / 下一只生物。
- **搜索快捷键 `/`**：呼出全息多维搜索中枢（输入中文名/学名/英文名/IUCN评级回车定位）。
- **手势图鉴**：点击右上角「手势图鉴」可查看所有动作说明，点击卡片可直接执行模拟交互。
- **顶栏「自动演示」**：开启展览自动轮播模式（每轮随机挑选 3 种海洋生物依次展开第一人称专属童声自述与全息照片显影，随后自动触发深海鲸落进入生命轮回并循环往复；任何用户交互即时丝滑退出）。
- **地球态「观测分布」**：按需显示当前物种的 GBIF 全球观测点；底部会明确标注实时记录、本地/离线缓存或档案栖息地回退状态。
- **物种卡「问问海瞳助手」**：在不遮挡物种照片的右侧抽屉中进行纯文本问答；需要先登录平台，关闭抽屉或切换生成会立即终止当前流式请求。

### 七大公开手势映射表

| 手势名称 | 动作要领 | 生效模式 | 交互功能说明 |
| :--- | :--- | :--- | :--- |
| **`palm`** | 五指持续自然张开 | `planet / diving` | 进入下潜并平滑放大，持续张开约 0.7s 开始显影真实动物照片 |
| **`fist`** | 五指握紧成拳 | 全部模式 | 关闭物种卡片并恢复地球；在 **whaleFall** 模式下可跳过鲸落动画 |
| **`ok`** | 拇指与食指捏合捏圈，其余三指伸展 | `species` | **固定 / 解除当前动物档案**；固定后挥掌不再翻页 |
| **`palm swipe`** | 张开手掌在镜像预览中左右挥动 | `species` | 巴掌左右挥切换物种；向左挥进入下一只，向右挥返回上一只海洋生物 |
| **`one / point`** | 食指单指伸出旋转 | `planet` | 跟随手指坐标顺畅旋转自转地球 |
| **`call`** | 竖起大拇指与小拇指（电话“6”手势） | 全部模式 | 启停背景音乐（薛之谦《跃》，仅限内部学习使用） |
| **`like` (彩蛋)** | 竖起大拇指 👍（比个赞） | `planet` | **唤醒深海终极隐藏彩蛋 · 一鲸落 · 万物生**（冷却 5 秒） |

## 🎵 声音场系统架构

`assets/js/soundscape-manager.mjs` 是海瞳系统的核心音频编排引擎（Web Audio 五总线架构：`masterGain → analyser → destination`；包含 `bgm` / `ambience` / `call` / `voice` / `sfx`）：

| 音频文件 | 类别 | 来源与授权说明 |
| :--- | :--- | :--- |
| `assets/audio/yue.mp3` | 背景音乐 | 薛之谦《跃》，**仅限内部学习/教学科研交流使用**，禁止商用 |
| `assets/audio/species/*-voice.mp3` (22首) | 个性化童声独白 | Edge-TTS + SSML 细粒度音高微调，海瞳项目自有离线生成资产 |
| `assets/audio/ambience/deep-sea.wav` | 深海环境声景 | 海瞳项目原创程序合成（水下低频与水听器声景），项目自有 |
| `assets/audio/easter-eggs/whale-fall.wav`| 鲸落五层合成音效 | 5层程序物理合成（36Hz次声、52Hz蓝鲸吟唱、海雪风铃），项目自有 |
