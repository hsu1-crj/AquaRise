# 视觉模型训练评估报告

## 1. 交付范围

本次交付为 TrashCan 1.0 Instance Version 的 22 类水下垃圾目标检测基线。训练采用 YOLO11n 预训练权重，数据集按 train/val/test = 5048/1442/722 划分。

## 2. 训练配置

| 参数 | 值 |
|---|---|
| 模型 | YOLO11n |
| epochs | 50 |
| batch | 16 |
| imgsz | 640 |
| device | CUDA device 0 |
| workers | 0 |
| seed | 0 |
| experiment | underwater_baseline_v1 |

可复现入口：`python -m src.vision.train`。训练结果保存在本地 `runs/detect/underwater_baseline_v1/`，不提交权重和数据集文件。

## 3. 结果

验证集最后一轮指标：Precision 0.8615、Recall 0.8542、mAP@50 0.8913、mAP@50:95 0.6886。验证集最佳 mAP@50:95 出现在第 49 轮，数值为 0.6890，因此部署和推理默认使用 `weights/best.pt`。

当前结果属于随机帧划分基线。由于同一视频的相邻帧可能被分到不同 split，指标可能高估跨视频泛化能力；后续正式对比应按视频 ID 分组划分，并以独立 test 集进行最终报告。

## 4. 推理交付

- 单图：`python -m src.vision.detect --source <image> --output <result.jpg>`
- 视频：`python -m src.vision.video_process --source <input.mp4> --output <output.mp4>`

两个入口均支持 `--model`、`--conf` 和 `--device` 参数。推理输出和模型文件属于本地运行产物，已由 `.gitignore` 排除。

## 5. 验收结论

训练已完成，模型评估曲线、混淆矩阵和验证集预测样例已生成；视觉模块具备训练、单图推理和视频逐帧推理入口，满足当前阶段代码提交标准。跨视频数据划分、误检漏检案例归因和 ONNX 导出属于下一轮优化事项。
