# LLM 模块 2026-08-21 更新记录

**日期**：2026-08-21  
**负责人**：海瞳 LLM 组（LLM 模块）  
**性质**：对话行为、报告闭环、快捷咨询和质量门禁升级（固定正式模型，不换模型、不接云端）

## 一、模型与范围约束

- 正式模型始终为 **`ds-ocean_mingzhe`**，未引入其他模型或云端 API。
- `deepseek-r1:1.5b` 仅保留为人工回滚基线，不参与正式链路。
- 本轮没有重写前端和检索架构，主要通过意图规则、确定性回答、证据门禁、报告上下文和提示词修复行为。

## 二、意图路由与确定性回答

- 收窄越界判断：海洋科普、海洋生态、污染治理、检测方法和平台功能问题留在海洋领域；只有明显无关的股票、编程、天气等问题返回范围说明。
- 修复专业问题被规则误伤：`作业` 不再单独触发越界；渔网处置、切割 SOP、回收利用、微塑料来源/富集、检测结果解读按意图分流。
- 补充问候、感谢、再见和无礼输入的自然回应。
- 补充海瞳平台、生命图谱、指挥大屏、污染分析、检测历史和报告页面等平台功能知识卡。
- 为快捷咨询及其追问增加有边界的确定性回答，覆盖：MARPOL 船舶塑料排放和 GRB/防污染证书核查、多帧跟踪与人工复核、图像去散射与超分辨率、ROV/潜水员幽灵渔网微创切割、废弃渔网脱盐分选与再生造粒、USV 漂浮垃圾巡航拦截、PET 老化与碎裂模型、微塑料光谱检测及 POPs 食物链富集机制。

这些回答只给出通用流程和边界，不编造未经验证的设备参数、寿命数字或法规细节。

## 三、RAG 与质量门禁

- 操作、方法、机制、计算、报告解读类问题增加核心意图证据门槛，避免“检索到了内容”被误认为“证据能回答问题”。
- 多帧跟踪要求同一证据句同时体现“帧/多帧”和“跟踪/追踪/关联”，不再接受跨句擦边拼贴。
- 报告解读证据收紧为“降级/风险标注/标注”等核心词，排除上传文件名、坐标、潮汐和清理记录等无关内容。
- 报告兜底将结构化 JSON 转为可读的风险等级、质量评分、关键发现和处置建议，绑定报告时不再丢失上下文。
- 模型输出残缺、思考痕迹、无依据数字/机构或不相关内容时，统一进入确定性答案、报告快照或友好资料不足兜底。
- `LLM_MAX_TOKENS` 调整为 768，并保留回答完整性检查，减少“说到冒号就断”的半截回答。

## 四、快捷咨询与真实链路验证

8 个快捷入口均已覆盖：海瞳平台、识别复核、珊瑚渔网处置、船舶塑料管理、微塑料风险、塑料袋降解、检测报告解读、海岸清理优先级。

在真实登录链路（管理员登录获取 JWT，再调用 `/api/v1/chat`）中完成 8 个首问和 10 类去重追问验证。验证结果：回答均有主题相关内容，无越界话术、无“正在构思回复”、无统一资料不足模板；追问中的重复问题复用同一确定性回答规则。
