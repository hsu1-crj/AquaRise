# LLM / 数字人模块 2026-08-23 工作记录

**负责人**：海瞳 LLM 组（LLM / 数字人）
**范围**：对话交互收尾、数字人舞台布局、窄屏兼容和回归验证

## 一、流式对话交互修复

- 定位 `streamChat()` 正常结束后 `ask()` 未释放 `busy` 的问题，导致回答已经完成但输入区仍显示“停止”。
- 在 `Assistant.tsx` 中增加统一 `finally` 收尾：正常完成、异常、Abort 均清理 `busy` 和 `controller.current`，并恢复输入框焦点。
- 增加 AbortController 身份校验，避免旧请求结束时覆盖新请求状态。

## 二、数字人舞台布局修复

- 修复 SDK 容器与 AquaCore 拟态舞台同时参与 flex 排版造成的横向挤压。
- 将 SDK 容器和拟态舞台固定到同一个 `.og-stage-viewport` 绝对定位层，保留 SDK 初始化所需尺寸。
- 修复窄屏媒体查询将 `body` 强制设为 `min-width:1024px` 的问题，增加舞台和主区域的 `min-width:0`，避免 769px 窗口出现横向裁剪和数字人偏到右侧。

## 三、验证

- 769×1333 窄屏浏览器回归：`body.scrollWidth=769`，舞台与拟态舞台中心偏差 `0px`。
- 流式问答回归：回答结束后停止按钮消失、发送按钮恢复、输入框可直接继续输入。
- `npm run build`：通过。
- `pytest -q`：6 passed。
