# LLM 与数字人升级汇报（2026-08-11）

## 本次目标

- 将项目默认 Ollama 模型统一切换为 `deepseek-r1:1.5b`，不再使用训练得到的 `ocean-assistant` 作为默认聊天模型。
- 改善海洋问答的真实性、专业性和与问题的相关性；优先利用并校验项目知识库。
- 优化聊天流式体验与数字人加载、思考、播报之间的过渡。
- 确保被问及开发者时，回答固定为：`这是海瞳 LLM 组的实训项目成果。`

## 已完成的修复与升级

### 1. 模型与配置

- 在 `src/backend/config.py`、`.env.example`、`src/LLM/chat_api.py` 中将默认模型切换为 `deepseek-r1:1.5b`。
- 统一了 Ollama 地址、温度、最大输出、保活时长、超时和 RAG 开关等环境配置。
- 已在本机通过 `ollama list` 确认 `deepseek-r1:1.5b` 已安装、可调用；旧 `ocean-assistant` 不再处于默认请求路径。
- 更新 `src/LLM/deploy/Modelfile` 与部署说明，使部署文档不再继续指向旧模型。

### 2. 回答质量与防答非所问

- 重新整理系统提示词：限定在海洋垃圾、污染治理、微塑料、MARPOL、检测结果解读和环保教育范围；要求先结论、再依据/行动建议，禁止编造数字、天气、来源和法规细节。
- 增加 DeepSeek R1 的 `<think>` / `thinking` 输出过滤，避免内部推理泄露到聊天界面。
- 针对小参数推理模型实测中出现的“复述问题、无依据套话、错误处置建议”等情况，增加回答质量门禁：
  - 先缓冲模型输出；
  - 拦截空答、复述、无证据模板话与关键领域缺失回答；
  - 不通过时不向前端展示错误半句，自动切换到确定性回答或知识库证据兜底；
  - 通过后以短句重新 SSE 输出，保持自然的阅读节奏。
- 增加业务范围收敛：天气、股票、编程、游戏、新闻等非项目问题会明确说明能力边界，不再交给模型胡乱回答。
- 增加高频且易出错问题的高精度回答：开发者身份、幽灵渔网及珊瑚附近渔网处置、塑料袋降解、微塑料、MARPOL、海岸清理和检测报告解读等。

### 3. RAG 与知识库

- RAG 改造成“双通道”：优先使用 Chroma + 向量检索；当前环境若缺少向量依赖，会自动切换到无第三方依赖的本地中文词法检索。
- 新增 `src/LLM/rag/lexical_retriever.py`，读取 `data/knowledge/*.md`，按中文 n-gram 与关键词匹配检索，当前可读取 52 个知识块。
- 增加最小相关性阈值，避免例如“天气”仅因偶然词命中而被错误注入海洋治理文档。
- 模型失败或输出不合格时，优先返回可追溯的项目知识库证据，不再直接输出无关的本地测试模板。
- 新增 `src/LLM/rag/audit_knowledge.py`，用于审计知识库中已知的夸张、伪精确和过时表述。
- 修订了以下知识文档：
  - `海洋垃圾降解周期表.md`
  - `海洋微塑料污染知识.md`
  - `MARPOL公约概要.md`
  - `海洋垃圾分类与特征.md`
  - `海洋塑料治理技术综述.md`
- 主要事实修正：
  - 不再将塑料袋降解年限写成单一、确定数字；强调“老化和碎裂不等于消失”。
  - 删除“每周摄入 5 克微塑料”等未经充分确认的确定性传播说法。
  - 不将微塑料风险和营养级放大写成绝对结论。
  - 移除已过时的国际塑料公约谈判时间表。
  - 对 MARPOL、治理设备效果和可降解塑料补充适用条件与边界。

### 4. 聊天与数字人体验

- 更新助手欢迎语、前端系统提示词和聊天常驻问题，使其聚焦“幽灵渔网处置、检测结果解读、海岸清理方案”。
- 数字人加载阶段增加自然状态文案和进度：加载引擎、连接服务、就绪、未配置/失败切换纯文本模式。
- 数字人未准备好时不再错误显示“思考中”；文本回答仍可正常生成。
- 流式生成的半句不再抢先作为数字人字幕；回答完整后才显示完整字幕并触发播报，避免字幕抖动、语音抢跑和加载态跳变。
- SDK 加载失败或未配置时，界面会明确说明已回退到纯文本模式。
