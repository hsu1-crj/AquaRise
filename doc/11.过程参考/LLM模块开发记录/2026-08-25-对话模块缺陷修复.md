# LLM / 数字人模块 2026-08-25 工作记录

**负责人**：海瞳 LLM 组（LLM / 数字人）
**范围**：海洋守护者纯文本对话模块缺陷 A–E 修复、多轮与事实门禁强化、向量 RAG 恢复、回归验证

## 一、多轮追问与重复答案修复（src/LLM/chat_api.py、src/backend/routers/chat_router.py、src/backend/services/llm.py）

- **检索历史融合**：`_build_retrieval_query()` 识别“上面、刚才、你提到、第一条”等指代型追问，将当前问题与最近一轮用户主题共同送入 RAG；普通新问题仍只检索当前轮，避免历史主题污染。
- **强证据重复门禁**：`chat()` 在强证据短路前取最近一条 assistant 回复，通过 `is_near_duplicate_answer()` 比较候选答案；重复度过高时改走本地 Ollama 模型链路，模型仍重复时用明确的追问资料不足说明收敛。
- **追问规则细化**：`direct_response()` 将 MARPOL 附则 V 的食物垃圾规则放在宽泛附则规则之前，区分粉碎/未粉碎、一般海域/特殊区域和 3/12 海里条件；微塑料“进入人体途径”也先于宽泛人体危害规则，回答摄入、吸入及经皮证据边界。

## 二、虚构公约与专名幻觉门禁（src/backend/services/llm.py）

- `_named_document_entities()` 提取书名号内或直接写出的公约、协议、法规、条例、法案和标准专名。
- `_unsupported_named_entities()` 要求专名或有效核心名称必须在实际检索证据原文出现；`_evidence_supports_requested_intent()` 同步拒绝未获证据支持的专名回答。
- `_knowledge_fallback()` 在专名零命中时不再拼贴相似主题文档，确定性说明“知识库未查到、无法确认”，并列出知识库实际包含的 MARPOL 附则 V、海洋环境法规、垃圾监测清理和海洋塑料治理主题。

## 三、材料对比与领域路由补强（src/backend/services/llm.py、src/LLM/rag/lexical_retriever.py）

- 扩充 PET、HDPE、聚合物、紫外老化、光氧化、水解、耐候、性能对比等领域词和词法检索信号。
- `direct_response()` 对 PET/HDPE 紫外老化比较给出带“以下为通识判断”的稳定答复，同时保留添加剂、颜料、结晶度、厚度、应力和海水温度等条件边界，避免把材料通识包装成无条件结论。

## 四、塑料瓶降解数字与 RAG 恢复（data/knowledge/海洋垃圾降解周期表.md、src/LLM/rag/lexical_retriever.py、src/backend/requirements.txt、src/backend/services/llm.py）

- 知识表补入塑料饮料瓶“常见科普估算约450年”，同一表格行明确这是持留/碎裂数量级而非完全矿化年限，并保留环境条件与微塑料限定。
- `_chunks_preserving_lines()` 改为优先沿标题、段落和表格换行切片，避免把对象、数字和限定条件拆开；数字门禁继续只放行问题或实际证据原文已出现的数字。
- 后端依赖补齐 `langchain-core`、text splitters、community、Chroma、HuggingFace embeddings、sentence-transformers 等 Python 3.13 / NumPy 2.x 兼容版本，并用 `protobuf==6.33.6` 避免与现有 Streamlit 冲突。
- 实际执行 `RAGService.initialize()`：`vector_ok=True`、检索器为 `OceanRetriever`，塑料瓶问题 Top-3 证据包含 450 年。

## 五、基础数学与附带回归收敛（src/backend/services/llm.py）

- `_safe_arithmetic_value()` 使用受限 AST，仅允许数字、括号、正负号和加减乘除，不使用 `eval`，并限制表达式长度和结果范围。
- `_deterministic_math_response()` 支持四则运算和标准鸡兔同笼方程，答对后附带海洋专业范围说明；诗词、首都等低价值范围外问题仍沿用原收敛策略。
- A/B/C 三级清理响应网格增加确定性定义：它是按垃圾密度、生态脆弱度与安全潮汐窗口形成的清理优先级，不是模型曾编造的面积/距离/时间网格；具体阈值必须按本海域数据校准。
