# LLM 模块 2026-09-03 工作记录：海洋守护者页面 UI 升级

**负责人**：mingzhe（LLM 模块）

## 一、背景

海洋守护者（Assistant 页）功能链路稳定后，对欢迎区与输入区的视觉细节做一轮升级，与海瞳生命图谱的设计语言（荧光青主题、expo-out 缓动、语义色圆点）拉齐。纯 CSS 改动，零逻辑变更。

## 二、升级内容

- **欢迎标题**：问候语改为海洋荧光渐变字（白→薄荷→天青的 background-clip 文字渐变）。
- **欢迎光核**：新增外圈慢速旋转虚线轨道（28s/圈），与中心数字人图标形成"天体轨道绕核心"的层次。
- **能力卡片（检测结果研判 / 质量报告解读 / 法规公约问答 / 治理方案咨询）**：
  - 错落浮入入场：四卡按 80ms 间隔依次上浮 + 模糊消入（expo-out cubic-bezier(0.16,1,0.3,1)）；
  - 每卡顶部主题色荧光 hairline（青/绿/紫/琥珀随卡），呼应海瞳引导弹窗的卡片语言；
  - hover 时图标瓦片放大 8%，箭头滑动保留。
- **快捷话题 chips**：每项前置四色轮换荧光圆点（青→蓝→琥珀→紫），与引导弹窗功能 chips 同语言。
- **发送按钮**：悬停流光扫过（斜切高光从左掠至右）。
- `prefers-reduced-motion` 下入场动画、轨道旋转与流光全部自动降级。

## 三、验证

- `npm run build` 构建通过（14.65s，chunk 体积警告为原有问题）。
- 零逻辑变更：TSX 未改动，仅 styles.css 追加升级块并按媒体查询降级。
