# LLM / 数字人模块 2026-08-25 下午工作记录

**负责人**：海瞳 LLM 组（LLM / 数字人）
**范围**：海洋守护者纯文本对话模块缺陷 F–J 修复、反事实质量门禁、海洋安全常识补强、上轮基线回归验证

## 一、领域百分比应用题确定性求解（src/backend/services/llm.py）

- 新增 `_parse_chinese_number()` 与 `_percentage_values()`，在受限范围内识别 `60%`、`六成`、`百分之六十` 等比例表达，不扩展成自由文本数学解释器。
- 新增 `_deterministic_percentage_response()`，仅在“基础数量与单位 + 一个或多个比例 + 明确求值意图”同时出现时计算连乘链；`2.5吨 × 60% × 30%` 稳定返回 `0.45吨`。
- 没有“多少、求、计算、是多少”等求值意图的百分比统计描述不被规则抢答，仍进入原有知识问答链路。

## 二、海洋常用单位换算（src/backend/services/llm.py）

- 新增 `_marine_unit_conversion_response()` 与有限白名单 `_UNIT_FACTORS`，覆盖海里/公里/米、节/公里每小时、吨/千克的双向常用换算。
- `direct_response()` 在范围门禁前调用换算规则，`1海里等于多少公里` 直接返回 `1.852公里`；未列入白名单的单位不尝试猜测。

## 三、开放反事实提示约束与质量降级（src/LLM/chat_api.py、src/backend/services/llm.py）

- `chat_api.py` 新增 `_is_counterfactual_question()` 与 `_counterfactual_instruction()`；`ChatService.prepare_messages()` 对“如果某机制不存在，会有什么变化”类问题注入【较确定推论】【推测】【不确定性】三段式约束，要求列出残余变量并禁止绝对化结论。
- `llm.py` 新增 `is_counterfactual_question()`、`_has_counterfactual_uncertainty_structure()` 和 `_has_material_microplastic_confusion()`；`is_acceptable_model_answer()` 拒绝缺少不确定性结构的反事实回答，以及把 PET、HDPE 等材质名称直接等同于微塑料的类别混淆。说明“小于 5 毫米的材质碎片属于微塑料”不会被误拦截。
- `_counterfactual_fallback()` 为门禁失败提供保守答案。月球潮汐问题明确太阳引潮力、风浪、洋流和岸形仍会作用，只做方向性推测，不再声称垃圾必然均匀分布。

## 四、海洋安全常识确定性规则（src/backend/services/llm.py）

- 新增 `_marine_safety_response()`，覆盖离岸流、涨潮受困和水母蜇伤三类高频海边险情，并统一提醒紧急情况下呼叫当地专业救援。
- 离岸流建议按“保持镇定与漂浮—不逆流硬游—沿岸平行脱离—斜向返岸—挥手呼救”组织；看到他人遇险时优先通知救生员和投递漂浮物，不鼓励无装备下水。
- 涨潮受困强调转移到稳固高处、不要冒险涉水、报告所在位置；水母蜇伤强调安全离水、不揉搓、谨慎移除触手和可耐受热水处理，醋的使用保留物种与当地指引边界。

## 五、低置信度结论先行与错误前提纠正（src/backend/services/llm.py）

- 新增 `_low_confidence_direct_response()`，识别 `0.6`、`60%` 等置信度表达；低于当前平台 0.7 复核口径时，首句直接说明“属于低置信度，建议人工复核，不作为正式统计依据”，再给原图、目标框、连续帧和补采样建议。
- `direct_response()` 补充“刚才说 3 年就能降解完”诱导前提校正：如果指塑料饮料瓶，明确纠正为常见科普估算约 450 年，并保留环境差异与碎裂成微塑料的限定。

## 六、回归测试（tests/test_llm_dialogue_regressions.py）

- 在上午 11 个专项用例基础上新增 9 个二轮用例，覆盖百分比连乘与非计算边界、单位白名单、反事实提示注入、类别混淆门禁、保守降级、三类海洋安全、0.6 结论先行和 3 年错误前提纠正；本文件共 20 个用例。
- 纯文本 API 完整实测 17 项检查：F–J、MARPOL 首问与食物垃圾追问、虚构公约、PET/HDPE、塑料瓶 450 年、错误前提、四则运算、鸡兔同笼、微塑料、A/B/C 网格、身份、乱码和中英混合提问，全部通过。

## 八、复核补充修复（外部 AI 复核后追加）

- **百分比口语问法漏判**：实测「PET 有几吨？」未命中求值意图正则（原只认「多少(吨)」），掉入知识库兜底。`_deterministic_percentage_response()` 的问句正则补 `(?:有)?几(?:吨|千克|公斤|克)` 分支；新增用例 `test_percentage_word_problem_supports_colloquial_how_many_tons`（六成/百分之三十/几吨 → 1.8吨）。`tests/test_llm_dialogue_regressions.py` 现共 27 个用例。
- **向量 RAG 首次检索阻塞事件循环**：嵌入模型 `bge-small-zh-v1.5` 加载时 huggingface_hub 在线校验在离线环境每次连接超时约 21 秒 × 5 次重试 × 多个配置文件，同步阻塞 FastAPI 事件循环，期间登录等全部接口无响应。`src/LLM/rag/knowledge_base.py` 在导入 langchain 前默认 `HF_HUB_OFFLINE=1`、`TRANSFORMERS_OFFLINE=1`（`setdefault`，显式设置可覆盖），权重走本地缓存。
- 复核验证：`pytest -q tests/` 27 passed；重启后端纯文本实测——口语占比题 `10×60%×30% = 1.8吨`、鸡兔同笼与 MARPOL 基线不变、统计描述句仍不被计算规则抢答；首次模型生成请求约 49 秒（含嵌入模型与 Ollama 冷加载），后续请求秒级返回。
