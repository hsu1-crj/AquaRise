# LLM 模块 2026-08-28 工作记录：答非所问与人机感专项修复

**负责人**：海瞳 LLM 组（LLM / 数字人协同）
**触发背景**：15 问真机批量诊断（15 类高频用户问题 × 完整链路）确认 9 类缺陷：概念问法被引用口径绑架、知识库有答案却被拒答、检索错配答非所问、事实错误直通、对比问题答一半、兜底开场白模板味、文档腔泄漏。
**方案基线**：不重新训练模型；不动 `_atlas_species_context_response` 物种档案路由；改动集中在运行时层（`src/backend/services/llm.py`），全部离线可验证。

## 一、病根诊断（15 问基线，见 `_diag_before.txt` 归类）

1. **requires_citations 泛词误伤**：正则含 `报告|多少|数量|rov|机制|方法|流程|步骤|操作` 等泛词，"ROV是什么""海洋温度多少度""经济效益多少""怎么区分PET和HDPE"全部被强制审稿式引用，模型正常回答被整段替换为 `[S1]` 摘录拼贴。
2. **概念问法被误判**："检测报告里的置信度是什么意思？"命中"报告+置信度"进入强制引用链，模型答对后仍被门禁拒绝掉审稿兜底。
3. **答不上**："水深超过多少米算深海？"知识库第一句就有答案（>200米），但模型乱编"中海/400米"被拒后 scope_response 直接拒答。
4. **检索错配**："塑料垃圾主要有哪些类型？"向量检索 Top1 是《来源与输运路径》，模型跟着答来源，完全不提类型。
5. **兜底拼贴文档碎片**："海龟为什么误食塑料袋？"掉兜底后输出《误区与事实核查》原文，带"核查：/正确表述："编辑前缀。
6. **事实错误直通**：小模型输出"塑料瓶由玻璃制成溶解度高""PET聚乙烯/HDPE聚高密度乙烯""聚丙烯（PC）"这类硬伤原样放行；"石油泄漏导致海洋酸化"等编造细节也无拦截。
7. **对比问题答一半**："石油还是塑料危害大"类问题模型常只谈单边就下排序结论。
8. **兜底开场白模板味**："根据项目知识库中与这个问题最相关的资料，可以确认："被用户点名批评。
9. **文档腔泄漏**：模型输出"本文介绍…供…问答使用"自指句、`## 标题`开头的文档结构复述、"ROV是什么东西？\nROV是…"的问题回声首行。

## 二、修复内容（全部在 `src/backend/services/llm.py`，一处同步 `src/LLM/verify_upgrade.py`）

### A. 引用口径三层收窄（`requires_citations`）
- 第一层强事实语境：`marpol|附则|法规|公约|条款|污染等级|污染指数|任务编号|监测数据|评分|统计|正式|纳入`。
- 第二层概念豁免：`是什么|什么是|什么意思|啥意思|的含义|的概念|的定义|简单解释|解释一下|介绍一下` 直接 False——科普问法不因命中领域词被绑架。
- 第三层操作/报告语境：`检测报告|置信度|点位|标准作业|sop|去散射|超分辨率|多帧|时序|跟踪|追踪|潜水员|切割|微创`。
- 移除的泛词：`报告|多少|数量|结论|rov|机制|方法|流程|步骤|操作`。verify_upgrade 同步：原 `requires_citations("图像去散射方法是什么？")` 改为等价强操作问法 + 新增概念豁免断言（行为变更同步，非削弱）。

### B. 新增确定性直答卡（`_direct_response_core`，共 9 张）
知识库口径逐条核对后编写，措辞全部有据：
1. **ROV 概念卡**：缩写、系缆供电/声学通信、与 AUV 区别；作业类问法（切割/SOP/打捞）显式排除防抢答。
2. **垃圾类型列举卡**：基于《海洋垃圾分类与特征》四大类 + 危害分级，直接修复检索错配。
3. **通用降解卡**：无统一数字 + 450年数量级 + "碎裂不等于消失"口径。
4. **瓶袋降解对比卡**：明说"没有可靠排序结论，不替档案编"，给两者确定事实 + 回收路径差异；排序在塑料袋单卡之前防抢占。
5. **石油 vs 塑料对比卡**：急性（油膜/羽毛/直接毒性）vs 慢性（缠绕误食/微塑料持久），不排序；门禁层另有对比覆盖检查兜底。
6. **为什么难治理卡**：持留性强/分布太广/来源分散三点 + 治理重心结论。
7. **温度实时数据卡**：承认无实时数据，引向 CTD 记录，邀请提供数据。
8. **置信度概念卡**（放在低置信度处置卡之后）：把握程度/不是准确率/低置信度先复核。
9. **经济效益卡**：承认无单价数据 + 材质纯度决定价值框架 + 政策工具影响。
另有：**深海定义卡**（>200米 + 分层差异声明）、**PET/HDPE 区分卡**（外观/回收代码/用途，"以当地体系为准"）、**海龟误食卡**（拟态水母机制，有据）。

### C. 材质配对错误拦截（`_has_material_pairing_error` + 门禁挂接）
- 正确配对表：聚丙烯→pp、聚乙烯→{pe,hdpe,ldpe}、聚苯乙烯→ps、聚碳酸酯→pc、聚氯乙烯→pvc、聚对苯二甲酸乙二醇酯→pet。
- `中文名（错误缩写）` 配对即硬幻觉一票否决；接入门禁 `is_acceptable_model_answer`。

### D. 对比问题覆盖门禁（`_comparison_answer_covers_both_sides`）
- 问句命中"A还是B"对比结构（限石油/塑料对，避免未知句式误伤）时，答案须覆盖双方、或声明只知一方、或明说没有排序结论；单边下结论退回兜底链。

### E. 证据摘录前缀清洗（`_evidence_excerpt`）
- 摘录句剥 `核查：/正确表述：/误区：/事实：/结论：/说明：/提醒：/注意：` 编辑前缀，误区核查类文档不再泄漏文档腔。

### F. 兜底文案去模板化 + 机制校验
- 引用版 opening 换为"这几条依据直接来自项目知识库，逐条列给你核对："（2 变体轮换），`_STYLE_EXEMPT_MARKER` 同步。
- `_knowledge_fallback` 新增机制意图校验：问句命中"为什么/机制/原理"而摘录无机制词（导致/因为/传递/富集等）时返回 None 走 `_friendly_unknown`，不再拿主题擦边的碎片硬凑。

### G. 门禁与后处理三件套
- `is_acceptable_model_answer`：`## ` 开头的文档结构复述整段拒绝。
- `_strip_query_echo`：首行与问题归一化同形时剥掉首行（救活 ROV 类被复述检查误杀的正确答案）；**逐字符比对内容**，首行不是回声时原样返回。
- `_strip_document_self_reference`：剥"本文/本节/以下内容介绍…""供…问答使用"自指句。三者接入 `finalize_model_answer`（strip_think → 自指剥离 → echo 剥离 → 门禁 → patch → 兜底）。

### H. DOMAIN_TERMS 补词
`深海|水深|降解|降解周期|石油泄漏|溢油|油污` 入域，上述问题不再被范围规则拒答。

## 四、遗留与说明

- 诊断中间产物 `_diag_llm.py`、`_diag_before.txt`、`_diag_after.txt` 用完即删，不入库。
- 对比覆盖门禁目前只对石油/塑料对生效，是刻意收窄：放宽到任意"A还是B"会误伤正常单边深答。后续如需泛化，先积累问法样本再扩。
