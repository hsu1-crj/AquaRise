## 1. LLM 模块 UI/UX 全面重构与体验优化

根据实训平台高规格交互设计要求，对智能助手「海洋守护者」进行全方位 UI/UX 重构：

### 1.1 AquaCore 全息拟态舞台（`AquaCoreStage`）
- **痛点**：数字人离线或未配置时界面空洞呆板。
- **重构**：打造了 3D 陀螺仪多重轨道旋转光环、等离子高亮呼吸球体、语音等离子跳动均衡柱（5 频段动态波形）与实时遥测信息胶囊。
- **状态联动**：待机（青蓝呼吸）、思考（琥珀光晕加速）、说话（翡翠绿波形跳动），带来生动的全息 AI 交互体验。

### 1.2 对话流与 Markdown 深度排版
- **代码块一键复制**：每个代码块右上角挂载专属复制按钮，支持点击一键复制并提供 `已复制 ✓` 视觉动效反馈。
- **消息操作栏**：每条回复底部集成「复制全文」、「语音重读（TTS 朗读）」与「点赞/实用反馈」三项实用操作。
- **智能排版**：全面优化 Markdown 标题、加粗、引用块、有序/无序列表与表格的夜间科技配色，消除阅读疲劳。

### 1.3 输入控制台与快捷操作
- **自适应伸缩文本框**：支持 1~5 行高度智能伸缩，支持 `Enter` 快捷发送与 `Shift + Enter` 换行。
- **字数实时统计**：右下角提供字符计数与清空按钮。
- **悬浮一键回到底部**：滚动离开底部超过 120px 时自动弹出带有动效的「最新内容」快捷导航按钮。
- **保留完整 8 大快捷提示词库**：保持原有 8 个针对海洋垃圾识别、MARPOL 法规、珊瑚保护等核心预设问题不变。

## 4. 建议追问自适应多轮上下文引擎（拒绝固定死板）

### 4.1 痛点与重构
- **原问题**：原追问建议仅依据简单的 4 个固定分支，问题固定死板，无法跟随对话内容深入演进。
- **全新架构**：构建基于 **「用户当前提问」+「海洋守护者最新回复」+「全量对话历史」** 的多维语义联合图谱推导引擎。

### 4.2 覆盖 10 大海洋环保专业知识图谱
1. **低置信度 / 浑浊去雾 / 图像增强**：时序多帧平滑、泥沙暗光超分辨率、降级复核机制。
2. **废弃渔网 / 幽灵渔具 / 珊瑚缠绕**：ROV 微创切割作业规范、废弃渔网脱盐造粒再生。
3. **微塑料 / 降解机理 / 食物链毒性**：红外拉曼光谱检测、POPs 复合毒性、真实海洋降解演化。
4. **塑料瓶袋 / 漂浮垃圾 / USV 拦截**：无人艇自主拦截装置、PET 力学老化衰减碎裂模型、FVCOM 洋流预测。
5. **MARPOL 国际公约 / 船舶排污 / 港口接收**：附则 V 特殊区域禁排、GRB 垃圾记录簿核查、联单制无害化处置。
6. **清理优先级 / 网格化巡检 / 复测评估**：A/B/C 三级响应网格、样方抽检达标评估、底栖无损清漂。
7. **环境质量评分 / 报告评级 / 预警联动**：100 分制权重算法、严重污染联合应急响应、生态环境部标准报告。
8. **海瞳 LLM 组 / 平台技术架构 / RAG 知识库**：LLM 领域微调、本地向量知识库挂载、22 类垃圾检测算法。
9. **危险废弃物 / 电池 / 油污腐蚀**：水下蓄电池原位封堵、重金属电化学溶出毒性、吸油分散剂工艺。
10. **海洋生物救护 / 鲸豚海龟 / 栖息地恢复**：海龟误食塑料紧急救援、内分泌干扰物、水下声学定点监测。

### 4.3 历史去重机制
- 自动识别并**过滤当前会话中已经提问过或讨论过的问题**，确保每一次对话后推荐的都是最新颖、最契合当下话题且可一键点击发送的高质量追问。
