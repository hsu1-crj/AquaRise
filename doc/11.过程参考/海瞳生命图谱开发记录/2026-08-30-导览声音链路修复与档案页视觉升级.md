# 海瞳·生命图谱 2026-08-30 工作记录：导览声音链路修复与档案页视觉升级

**负责人**：海瞳 LLM 组（LLM / 数字人协同）

本篇记录两轮迭代：第一轮解决"自动导览只有画面、没有声音"的缺陷（含一个导致所有 `replace` 播放静默失败的仓库级历史 bug）；第二轮响应用户"档案页面 UI 升级"与"地球上有磨砂模糊的东西"两条反馈，完成档案卡视觉重排与地球点阵着色器调优。全部改动通过 43 项模块回归、生产构建与真实浏览器逐项实测。

## 一、触发背景

- 用户追问自动导览"关键是声音匹配嘛，就是自动放嘛"——实测发现导览只自动切画面，物种独白从未响起。
- 档案页按钮层次混乱（四种按钮样式堆叠）、威胁标签与声音标签样式雷同、图片来源行孤悬、濒危徽章顶到屏幕边缘。
- 地球表面点阵后面浮着一层绿色/土黄色的"磨砂色块"，观感像蒙了雾。

## 二、病根诊断

1. **导览声音从未出声（soundscape-manager.mjs，仓库历史 bug）**：`playTrack` 开头 `const gen = ++this._generation[kind]` 登记代次，随后 `replace:true` 路径调用 `stopKind(kind)` 做同声道替换——而 `stopKind` 内部同样 `this._generation[kind] += 1`，紧接着的 `if (stale()) return { ok:false, interrupted:true }` 检查必然命中。**每一次 `replace` 播放都在起播前把自己判死**：物种独白、动物叫声、栖息地环境声、"听它讲述"按钮全部静默失败，且无任何状态/控制台痕迹（测试只测了纯函数所以全绿）。
2. **解锁时机脱离手势栈（index.html）**：`#demoBtn` 点击处理不调用 `soundscape.unlock()`，音频解锁发生在 `playTrack` 内部资源探测的若干 `await` 之后，严格自动播放策略（iOS Safari 等）下 `resume()` 因脱离用户手势调用栈被拦。
3. **导览等待策略掐断独白（index.html）**：`waitForDemoNarration` 固定最多等 3.2s 就切下一物种，而 `revealComplete` 要等"叫声"整段播完才开始播"独白"——即使声音能播，也几乎总在独白开始前被切换掐断。
4. **档案页视觉问题（index.html 桌面覆盖层）**：操作区四种按钮样式堆叠无层次；威胁标签与声音预载芯片同为青色系胶囊，语义不分；图片来源行夹在标签与按钮之间；卡片右侧内边距为 0，徽章/读数顶到屏幕边缘，渐变尾部透明导致右缘对比度不足；卡片无最大高度限制。
5. **地球磨砂（index.html 粒子片元着色器）**：每个粒子自带宽软光晕（`halo = exp(-d*4.8)`，权重 0.32），陆地粒子又比海洋粒子更大更不透明（3.0px / alpha 0.86+ vs 1.75px / 0.78），高密度下相邻光晕互相融合成连续"磨砂色块"。

## 三、修复内容

### A. 播放代次自我作废修复（soundscape-manager.mjs）

- `playTrack` 代次改为两段式：探测/解锁阶段用 `preGen` 快照做 `superseded()` 前置校验（外部 stop 仍能作废本次调用）；`replace` 的 `stopKind` 执行完之后再 `++this._generation[kind]` 登记新一代次，此后的外部 stop 才能打断播放。修复后独白/叫声/环境声/声纹回响全部可正常起播，"迟到旧调用杀新轨道"的防抖语义不变。
- 新增 `tests/soundscape-manager.test.mjs` 三项回归：`replace` 播放不得被自己触发的 stopKind 作废、外部 stopKind 仍会打断、循环环境声起播后保持 playing。

### B. 导览声音链路（index.html + atlas-guide.mjs）

- `#demoBtn` 点击处理在手势调用栈内同步 `soundscape.unlock()`（附注释固化原因）。
- `waitForDemoNarration` 改为监听独白 Promise 结束标记：新增 `resolveDemoNarrationBudget({ kinds })`（atlas-guide.mjs 纯函数）——任一物种声道在响时给 45s 预算等独白完整播完再切换；全部被浏览器拦截或资源缺失时保持 3.2s 快速节奏保住导览流程。
- 导览入口文案统一为"自动导览 / 停止导览"单一入口（上轮收尾），开启 toast 同步为"将依次讲述三个物种并展示鲸落"。

### C. 档案页视觉升级（index.html，纯 CSS，DOM 与 JS 钩子零改动）

- 档案头两行化：`.card-kicker-group{display:contents}` + `.card-top::after` 强制断行，第一行"档号 + 就绪状态"、第二行"濒危徽章 + 进度读数"；EX 物种的时光回溯徽标独占一行。
- 操作区 `grid-template-areas` 四组层次：听它讲述（主按钮全宽）→ 问海瞳助手｜观测分布 → 生成科普海报｜权威来源 → 返回地球（全宽导航）；权威来源与返回地球从"透明文字"升级为可见按钮。
- 威胁标签改暖琥珀色调（风险语义），声音芯片加波形小图标（交互语义），二者不再混淆。
- 卡片右侧补回 30px 内边距、渐变尾部提至 0.32 不透明度保证对比度；简介 12.5px/1.8 行距；图片来源移至底部脚注；卡片增加 `max-height` 与细滚动条防矮窗裁切。
- 桌面/EX 红色变体/移动端 390×844 均实测通过（移动端底部抽屉媒体查询未改动，程序化断言布局正常）。

### D. 地球点阵去磨砂（index.html 粒子片元着色器）

- 光晕衰减 `exp(-d*4.8)` → `exp(-d*7.5)`，透明度权重 0.32 → 0.18，核心 `exp(-d*d*32)` → 40 并微调亮度配比；点阵恢复"清晰光点 + 可读大陆着色"，磨砂膜消失，外圈大气辉光与边缘光保留。改动仅 11 行，注释固化调参原因。
