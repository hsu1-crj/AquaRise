## 模块简述

本目录归档由总策划 **`mingzhe`** 规划推进的「海瞳 · 生命图谱 (Bioluminescent Atlas)」向 AquaRise 智慧海洋监测平台（`issedu_ysu2026_7439`）的完整嵌入过程文档。

包含了系统架构、侧边栏导航适配、页面组件 `MarineAtlas.tsx`、22 种生物专属童声独白矩阵、MediaPipe 30 FPS 手势无感交互、深海终极隐藏彩蛋（竖大拇指 👍）、六大顶级浪漫交互特性及前端 Vite 生产构建验证记录。
