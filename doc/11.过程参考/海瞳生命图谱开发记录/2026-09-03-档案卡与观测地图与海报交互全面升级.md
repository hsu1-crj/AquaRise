# 海瞳·生命图谱 2026-09-03 工作记录：档案卡与观测地图与海报交互全面升级

**负责人**：mingzhe（LLM 模块 / 生命图谱）

## 一、物种档案卡操作区重设计

- **统一按钮规格**：主操作（听它讲述，44px 荧光渐变填充）+ 次操作（问海瞳助手 / 查看观测分布 / 生成科普海报 / 权威来源，同款幽灵按钮 42px）+ 导航（返回地球，最弱层级），消除原先五种高度、五套配色的混杂。
- **声音状态条**：从大磁贴压成细状态条——左侧通道色条（青=播放 / 琥珀=暂停 / 灰=待机）+ 四柱声纹波形（播放时逐柱跳动），状态与按钮一眼可辨。
- 查看观测分布按钮收成单行标签 + 右侧状态点（开/加载/关）。

## 二、观测分布平面地图两轮升级

- **观测点视觉**：自绘扁圆升级为预烘焙辉光精灵（白核→琥珀→光晕），带逐点错相位呼吸涟漪；数据载入时错落浮现（easeOutCubic）。档案参考点（离线回退）以金色 + 慢速旋转虚线环区分。
- **交互**：右上角缩放按钮组（+/−/复位，Leaflet 惯例）、viewTarget 指数缓动追踪（GSAP 式平滑）、拖拽平移（1× 带 24px 回弹）、滚轮以光标为锚缩放、双击复位、悬停高亮 + 坐标/元数据提示、底栏光标经纬度实时读数。
- **信息可读性**：悬停提示补充 GBIF 元数据（观测日期 / 记录类型中文化 / 地点）；底栏统计改为“N 条观测记录 · N 个聚集区”；图例标注“同网格记录合并为聚集区”。
- **缓存 v2**：缓存记录携带元数据（日期/记录类型/地点，与坐标逐条对齐、同抽样同缓存），升级前缀自然失效旧格式并一次性清扫 v1 键，根除“元数据缺失”状态。
- 图例侧栏移除，信息并入地图面板；面板弹性入场。

## 三、过程中抓到并修复的三个真 Bug

1. **地图滚轮事件冒泡**到页面级 wheel 监听，驱动背后地球 targetZoom，导致关闭地图后被意外拉回星球态（页面滚轮排除列表加入 #gbifFlatMap + 画布内 stopPropagation）。
2. **入场时间戳时钟源错乱**：`typeof performance === "function"` 守卫笔误导致回退 Date.now()（纪元时间），与 RAF 帧时间（页面相对）相差 1.7 万亿毫秒，观测点入场进度恒为 0——真实用户场景复现并修复。
3. **海报灯箱原生图片拖拽**抢占指针事件，拖动海报变成“复制图片”幽灵（draggable=false + dragstart preventDefault + user-select none）。

## 四、海报系统升级

- **品牌徽记与站点统一**：海报 Logo 逐几何复刻 favicon.svg（深空底圆、虚线轨道与两极节点、双弧眼睛流线、虹膜环、渐变瞳孔），文字锁定平台组合“海瞳 HAITONG + 海洋全域智守平台”，与浏览器标签栏图标一致。
- **灯箱缩放交互**：滚轮以光标为锚缩放（100%–500%）、拖拽平移（平移量随缩放溢出夹紧，1× 带 18px 回弹）、双击放大/还原、底部 −/百分比/+/⟲ 控制条、ESC 或空白处关闭。
- **日期实时化**：REC 日期、年月标注、英文月份刊名与期号全部取系统当前时间，不再硬编码。

## 五、引导与手势图鉴

- **三步引导弹窗两轮精修**：三步三色主题（01 选择=荧光青、02 下潜=深海蓝、03 阅读=暖琥珀）贯穿徽章/标题/提示 chip/hover 光晕；第二轮升级为图标瓦片 + STEP 01/02/03 编号体系（检索镜/下潜波/档案册线性图标）；功能 chips 四色彩点 + 加粗标签；主按钮实填充 + 悬停流光；入场为模糊上浮错落（expo-out）。
- **手势图鉴**：巴掌左右挥卡片动画重做（五指掌面水平扫动 + 方向箭头交替点亮 + 速度线，与左挥下一物种/右挥上一物种语义同步）；英文码 chip 精简为单词（swipe/point/ok）且不换行，按手势配色。

## 六、全局提示栏（toast）重设计

- 玻璃拟态卡片 + 类型化图标盘：info(青✦)/success(绿✓)/warn(琥珀!)/error(红✕) 四种语义，按文案关键词自动分型，全项目 40 余处调用零改动受益。
- 手势相关提示自动切换为对应手势的动态简笔图标（挥掌摆动/握拳脉动/点赞弹跳等七种）。
- 位置上移至顶部居中 66px，z-index 置顶（弹窗打开时也可浮现），reduced-motion 下动画静止。

## 七、首页 HUD 与转场

- **探索导航栏**玻璃卡片化：步骤连线、active/complete 态、工具区按钮化；摄像头开启时自动下移让位（:has 选择器），不遮挡摄像头画面。
- **深度滑条生命周期**：下潜与档案阶段常驻（显示当前深度），开始返回地球时向右滑出淡出（expo-out 0.55s）。
- 物种模式摄像头小窗泊位到左下角全屏按钮上方（避开档案照片与全屏按钮），位置切换带缓动。
