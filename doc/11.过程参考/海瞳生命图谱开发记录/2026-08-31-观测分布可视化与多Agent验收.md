# 海瞳·生命图谱 2026-08-31 工作记录：观测分布可视化与多 Agent 验收

**负责人**：统筹 Agent（与视觉审查、移动端 QA、成果审核 Agent 协作）

## 一、触发背景

用户反馈生命图谱的“观测分布”只能看到小点和不易理解的连线，无法判断它们代表什么；进入观测模式后还出现入口消失、状态提示遮挡和窄屏布局不清晰的问题。本轮目标是让“观测聚集区、档案代表点、地球参考底图”三类信息一眼可区分，并完成桌面、平板、手机三档验收。

## 三、实现内容

### 1. 观测数据视觉层级

- GBIF 坐标按地理网格聚合，聚集区数量由靶心大小和标签数字表达，避免 100 个位置重叠成一团光斑。
- 橙色靶心表示“观测聚集区”，金色小点表示“档案代表点”；两者使用不同颜色、尺寸和图例符号。
- 观测模式下压低海洋、陆地和海岸底图的亮度与饱和度，隐藏板块、迁徙和网格装饰，避免把背景误认为观测连线。
- 图例改为“浅色点列 = 地球轮廓参考”，并明确说明其不是观测数据。

### 2. 标签与响应式布局

- 修正 Three.js/WebGL 到 DOM 的 Y 轴换算，标签和实际靶心使用同一屏幕坐标。
- 增加标签碰撞避让：按聚集区数量优先放置，其他标签在上下、左右候选位中寻找不重叠位置；左侧标签的引线方向同步翻转。
- 平板（901--1200px）图例在四个安全候选位中动态选择，降低遮挡聚集点和底部操作区的概率；跨断点时清理内联定位。
- 移动端图例、观测模式关闭按钮、底部提示和搜索条保持独立安全区，按钮关闭后恢复普通地球模式。
- 图例接管滚轮和指针按下事件，说明区域不会把滚轮继续传给地球缩放。

### 3. 状态文案与数据诚实性

- 观测切换不再弹出会覆盖“观测模式/关闭图层”按钮的全局 Toast，加载状态直接显示在图例中。
- 页面文案使用“显示 N 个采样位置”，不把渲染上限误写成 GBIF 总记录数；聚集标签使用“个位置”。
- 加载、缓存、实时和档案回退状态继续通过图例来源和底部归因文字区分。

## 四、验收结果

- 390×844：两个相邻聚集区标签不再重叠；图例与搜索条、关闭按钮无矩形重叠；点击关闭后图例和关闭入口正常隐藏。
- 1024×768：图例使用自适应安全位置，标签避开图例；底部搜索区可继续操作。
- 1440×900：橙色靶心、数量标签和引线同屏对齐，图例不遮挡主要观测点。
- 观测层状态：注入 100 个确定性缓存位置时，运行时显示 2 个聚集区，靶心大小和标签数量一致。
- 观测图例滚轮已隔离；页面外滚轮仍保留地球缩放行为。
