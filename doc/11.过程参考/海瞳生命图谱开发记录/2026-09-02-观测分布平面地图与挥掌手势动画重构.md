# 海瞳·生命图谱 2026-09-02 工作记录：观测分布平面地图与挥掌手势动画重构

**负责人**：mingzhe（LLM 模块 / 生命图谱）

## 一、问题

1. **观测分布渲染形态**：GBIF 观测点以橙色靶心渲染在 3D 球体表面，背面聚集区不可见、标签与图例互相遮挡，交叉测试反馈希望改为"平面世界地图 + 保留交互体验，不再依赖球体"。
2. **手势图鉴动画与名称不一致**："巴掌左右挥 · 切换物种"卡片复用的是 `animWaveSway`（原地 ±12° 摆动 ±3px），且旧图标掌面轮廓不清晰，动作与名称对不上，容易误导测试人员。

## 二、修复

### 观测分布 → 平面世界地图

- 新增 `assets/js/gbif-flat-map.mjs`：等距圆柱投影（equirectangular）平面地图，陆地底图由离线 720×360 陆地掩码（`EARTH_MASK_720`）一次性渲染为离屏画布（陆地内部/海岸双色，经度方向环绕采样）；纯函数（投影、视图变换、命中测试、掩码解码）与 DOM 控制器分离，可被 Node 单测。
- 交互：拖拽平移（视图夹紧，地图不允许拖出边缘）、滚轮以光标为锚缩放（上限 6×）、双击复位、悬停高亮环 + 坐标提示（如 `64.0°S · 65.0°W`）；`prefers-reduced-motion` 下观测点不脉动、过渡禁用。
- 状态复用原链路：加载态、GBIF 实时/本地缓存/档案参考点来源徽标、位置与聚集区统计全部保留；打开入口不变（物种卡「查看观测分布」/「观测模式」），关闭支持右上角 ×、Esc、点击遮罩三条路径，关闭后保持进入前视图（物种模式不再强制返回地球）。
- 移除球面靶心图层配套的 `#gbifLegend` 图例侧栏（HTML/CSS/JS 引用全部清理），图例信息并入地图面板头部与底栏。

### 巴掌左右挥动画重构

- 新 SVG：五指张开的掌面（与 palm 卡同一掌形语言）+ 水平运动速度线 + 左右方向箭头。
- 新动画 `anim-swipe`：整掌水平扫动（±5px，带 ±2.5° 摆动），左右箭头与手掌位置严格同步交替点亮——0% 相位左箭头亮（左挥=下一物种），50% 相位右箭头亮（右挥=上一物种）；`reduced-motion` 下全部动画禁用。
- 旧 `animWaveSway` 保留给 `.anim-peace` 兼容类，不再用于该卡片。

### 过程中发现的缺陷（当场修复）

- 地图画布的滚轮事件冒泡到页面级 `window` wheel 监听器，会驱动背后地球的 `targetZoom`——实测在地图上缩放后关闭，物种模式被拉回星球态。修复：页面滚轮排除列表加入 `#gbifFlatMap`，地图画布 `wheel` 监听器内 `stopPropagation()` 双保险。
