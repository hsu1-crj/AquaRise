# 海瞳·生命图谱 2026-08-28 工作记录：使用指南视觉升级与观测分布入口增强

**负责人**：海瞳 LLM 组（LLM / 数字人协同）

本篇记录同日（首次使用指南功能随 262046f 提交验收之后）追加的两轮体验迭代，改动仅涉及 `public/haitong/index.html` 与 `assets/js/atlas-guide.mjs` 两个文件：第一轮针对用户"指南太丑"的反馈完成使用指南视觉重设计，顺带根治首次进入自动弹出从未生效的潜伏缺陷；第二轮补齐指南内摄像头直通入口、增强顶部"观测分布"入口的视觉权重，并同步第 03 步与 lead 文案。全部改动已通过用户方真机复核与三套自动化回归。

## 一、触发背景

- 用户反馈使用指南"太丑"：样式平淡、与页面其他弹层模块的质感脱节。
- 复测另发现两个入口层问题：一是指南通篇没有"开启摄像头"的直达入口，想体验 AI 手势的新用户只能自己在页面上找；二是顶部"观测分布"按钮与普通筛选按钮视觉权重相同，难以发现——上午验收解决的是"进入档案后可用"，"找得到"仍未解决。

## 二、病根诊断

1. **指南样式平淡（index.html coach 样式段）**：旧版卡片为扁平方块——`background:rgba(3,15,27,.64)` 单色底、1px 细边框、圆角 14px；编号为 30×30px 方形小块（9px 圆角、10px 字号）；字号整体偏小（卡片标题 12.5px、正文 10.5px、快捷键提示 9.5px 裸文本）。而同页手势图鉴弹层已是"衬线标题 + 徽标横幅 + 手势卡片（带 `animPalmPulse` 等循环动画的 SVG 图例 + hover 抬升）"的质感，两相对比，指南观感像临时占位。
2. **首次进入自动弹出从未生效（atlas-guide.mjs）**：`createAtlasGuideVisitTracker` 第三参默认值为 shorthand 裸引用 `timers = { setTimeout, clearTimeout }`——对象字面量 shorthand 取值时函数的 `this` 绑定到 timers 对象本身，新版 Chrome 按规范对未绑定到全局的 `window.setTimeout` 直接抛 `TypeError: Illegal invocation`（控制台执行 `({setTimeout}).setTimeout(()=>{})` 可复现）。于是 `scheduleAutoOpen()` 内 `timers.setTimeout(...)` 一调用即抛错，index.html 中 `maybeShowUsageGuide()` 的 `scheduleAutoOpen(openUsageGuide, 2600)` 链路从未走通，首次进入自动弹出一直静默失效。此缺陷藏在默认参数里：单元测试显式传入 timers，因此测试全绿也未能暴露。
3. **摄像头入口不可发现（index.html）**：指南动作区只有"开始探索 / 查看手势图鉴"两个按钮，而"查看手势图鉴"只开手册、不碰摄像头；lead 段还写着"不需要开启摄像头"。全页真正的摄像头入口只有两处——顶部导航 `#gestureBtn` 的"手势"两字按钮，与底部提示条 `#bottomHint` 内 `#hintGestureBtn`（inline 样式 `font-size:10px` 的"开启摄像头"小钮）——新用户从指南离开后没有任何一条直达摄像头授权的路径。
4. **观测分布按钮权重不足（index.html）**：旧 `.gbif-toggle` 与普通筛选钮同款待遇——暗底 `rgba(5,24,42,.70)`、1px 细边框 `rgba(135,222,255,.25)`、11px 等宽字单行文案，淹没在 CR/EN/VU/EX 一排小按钮里毫无辨识度；只有激活后 `.on` 的青绿渐变才显眼，但用户得先找到它才能激活。

## 三、修复内容

### A. 使用指南视觉重设计（index.html）

- 头部新增 58px 发光罗盘徽标 `.coach-emblem`（罗盘环 + 潜航轨迹 + 生物荧光浮标 SVG），配 `coachEmblemGlow` 3.2s 呼吸辉光动画。
- 标题 h2 改用 `var(--font-serif)`（Cinzel / Noto Serif SC）24px/700，与手势图鉴标题同一字体语言；面板顶部加 1px 流光缝线，关闭钮 hover 旋转 90°。
- 步骤编号由方块改 38px 圆形发光浮标（4px 外圈光环 + 双层辉光，卡片 hover 时增亮）。
- 两列卡片之间新增 2px 中央"深度光柱"（`.coach-steps::before`，自上而下由亮渐暗，海面→深海渐隐的下潜隐喻）。
- 卡片升级：深海渐变底 + hover 抬升 3px、边框点亮、角部径向高光；`coachRise` 四卡 stagger 入场（.05/.14/.23/.32s 依次延迟）。
- 快捷键提示胶囊化：em 由裸文本改为圆角胶囊（细边框 + 浅青底）。
- 动效可达性与响应式：`prefers-reduced-motion: reduce` 下 coachRise / 徽标呼吸 / gbif 徽标旋转动画全量关闭；≤900px 单列布局并隐藏深度光柱。

### B. 首次进入自动弹出修复（atlas-guide.mjs）

- timers 默认值改为 `setTimeout.bind(globalThis)` / `clearTimeout.bind(globalThis)`，并以注释固化原因防止回退；`scheduleAutoOpen` / `cancelAutoOpen` / `markSeen` 逻辑零改动，导出签名不变（显式传入 timers 的测试与调用方均不受影响）。

### C. 摄像头直通入口（index.html）

- 指南动作区新增 `#coachStartCamera`"开启摄像头手势"按钮：点击先 `dismissUsageGuide({ restoreFocus: false })`，380ms 后调 `toggleGesture()`——与既有"查看手势图鉴 → 380ms 后 openGestureGuide"同一节奏，避免两层弹窗交叠。
- 新增 `MutationObserver` 监听 `#coachMarks` class 变化，按 `gestureRunning` 把按钮文案同步为"开启摄像头手势 / 关闭摄像头手势"，保证重开指南时按钮状态与摄像头真实状态一致。

### D. 观测分布入口增强（index.html）

- 按钮结构升级为"徽标 + 双行文案"：32px 发光徽标（地球 + 倾斜轨道 + `gbif-sat-dot` 荧光卫星点 SVG）；文案改为 `strong`"观测分布"（12px）+ `small`"全球物种记录"（9px 等宽字）双行；min-height 40→46px，青绿描边 + 深海渐变底，独立 hover / focus-visible 样式与 2px outline 焦点环。
- 状态样式适配新结构：`.on` 激活态下徽标反色、副行文案同步变色；`.loading` 旋转动画由旧 `.gbif-toggle-dot` 移至 `.gbif-toggle-emblem svg`（gbifLoading 0.9s 周期不变）。
- 显示模式切换规则原样保留（`#filterHub.planet-mode` / `.species-mode` 下显示）；新增 ≤768px 缩窄适配（降高至 40px、隐藏副行）。

### E. 文案同步（index.html）

- 第 03 步改为引导点击顶部"观测分布"按钮，并注明查看的是该物种的 GBIF 全球观测记录。
- lead 段补充摄像头入口指引："想体验 AI 手势，可直接点下方'开启摄像头手势'"。
