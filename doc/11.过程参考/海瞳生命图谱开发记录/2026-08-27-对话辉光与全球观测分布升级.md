# 海瞳·生命图谱 2026-08-27 工作记录

**负责人**：海瞳 LLM 组（海瞳生命图谱 / LLM 数字人协同）

本轮仅升级电脑端生命图谱，保持近期已优化的 LLM 后端、模型、RAG、路由与提示词不变。新增物种对话入口、选择性 Bloom 生物荧光与 GBIF 全球观测分布，并完成 1280×720、1440×900、1920×1080 三档桌面视觉回归。

## 一、物种档案与本地海瞳助手联动（`public/haitong/index.html`、`assets/js/atlas-chat.mjs`）

- 物种卡新增「问问海瞳助手」入口，打开右侧 480px 桌面对话抽屉，抽屉接管档案卡阅读区而不遮挡物种照片。
- 严格复用平台 `POST /api/v1/chat` 流式协议、`aquarise-token` 登录令牌与 `haitong-chat-session` 会话标识；未接入云端模型，也未修改后端 LLM 链路。
- 首次提问或切换物种后自动在实际请求中加入中文名、英文名、学名、IUCN 等级和威胁标签，界面仍只显示用户原问题。
- 增加停止生成、重新生成、15 秒首字节超时、30 秒失败冷却与关闭时中止请求；Escape 顺序调整为海报灯箱 → 对话抽屉 → 其他弹层 → 退出图谱。
- 安全 Markdown 只允许有限强调、行内代码、段落与来源标记，原始 HTML、脚本和事件属性均作为文本转义。

## 二、选择性 Bloom 与性能自动降级（`public/haitong/index.html`、`assets/js/bloom-policy.mjs`）

- 本地内置 `postprocessing@6.38.3`，该版本的 Three.js peer 范围覆盖项目 r160；版本、完整性与许可证记录在 `assets/vendor/postprocessing/`。
- 复用既有单一 `WebGLRenderer`、场景与相机，以 `EffectComposer + RenderPass + BloomEffect` 增强粒子高光，不新建 WebGL 上下文。
- 默认开启 Bloom；系统启用减少动态效果时直接使用基础渲染。
- 以 240 帧滚动平均监测真实性能，平均帧率持续低于 30 FPS 达 60 个窗口后，本会话释放 composer 并永久回落基础渲染，只提示一次。
- resize 同步更新 renderer、composer 与像素比；调试对象 `window.__LIFE.perf` 暴露实时帧率、Bloom 状态、滚动平均和降级原因。

## 三、GBIF 全球观测分布（`public/haitong/index.html`、`assets/js/gbif-client.mjs`）

- 地球模式新增「观测分布」开关，按需读取当前物种的 GBIF species match 与 occurrence search 数据；普通进入页面不请求外网。
- 对经纬度做有限值、范围和重复点清洗，每个物种随机抽样最多 100 点；使用预分配 BufferGeometry 与独立 ShaderMaterial 绘制脉冲青绿点，不重建粒子地球。
- 观测结果按物种缓存 7 天；刷新失败时优先显示离线缓存，无缓存则回退到档案代表性栖息地。底部明确显示物种名、实时记录/本地缓存/离线缓存/档案回退和点数，避免把回退数据冒充实时记录。
- 连续两次联网失败后，本会话停止继续请求 GBIF；自动演示仅串行预热本轮 3 个物种，避免进入页面即批量请求和接口突发。
- 当前测试环境访问 GBIF 被浏览器报 `ERR_NETWORK_ACCESS_DENIED`，确认不是 CORS；回退链路正常，因此未增加后端代理，也未触碰 LLM 后端。

## 四、桌面视觉与交互质量（`public/haitong/index.html`）

- 在 1280×720、1440×900、1920×1080 三档检查按钮位置、地球主体、来源署名和观测点辨识度。
- 1280 与 1440 宽度下将地球态检索/观测工具条下移至顶栏下方，消除与背景音、自动演示和手势按钮的重叠；1920 宽度保持顶部紧凑布局。
- 观测点大小调整为 8.5 CSS 像素并保留正面衰减、脉冲和 Bloom，保证可辨识但不遮盖大陆点阵与迁徙弧线。
- 冥想状态下工具条会暂时放弃点击命中；真实鼠标移动会先唤醒界面，桌面自动化按同样动作完成验证，未破坏既有 12 秒冥想设计。
